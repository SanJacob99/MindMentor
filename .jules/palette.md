## 2024-04-03 - [Focus Rings on React Native Web]
**Learning:** Text inputs in React Native don't have built-in focus styling when rendered on the web, and relying on default browser outlines (which can be overridden or look out of place) hurts keyboard accessibility and visual consistency. However, adding dynamic borders using an `isFocused` state works perfectly, provided you suppress the default web outline to prevent double rings.
**Action:** Always add explicit focus states (e.g. border color changes on focus) for text inputs and use `style={Platform.OS === 'web' ? { outlineStyle: 'none' } as any : undefined}` to suppress default browser outlines when targeting web builds in Expo.
